Không thể đọc file dữ liệu

File bạn chọn có định dạng .docx và dung lượng 8.4 MB, không đúng yêu cầu của hệ thống.

Yêu cầu định dạng file để nhập thiết bị:
• Định dạng được chấp nhận: CSV (.csv) hoặc JSON (.json)
• Dung lượng file tối đa: 5 MB
• Dữ liệu thiết bị bắt buộc gồm 3 trường: Mã thiết bị, Tên thiết bị, Vị trí
Ứng dụng chỉ đọc nội dung file dưới dạng dữ liệu.
Trạng thái: File không hợp lệ, không nhập gì

Xuất danh sách thiết bị ra file

Dữ liệu sẽ được xuất bao gồm:
Danh mục thiết bị: 6 thiết bị (TB-001 ... TB-006)
Thời điểm trích xuất: 6 thiết bị (TB-001 ... TB-006)

File xuất chứa đầy đủ thông tin: Mã thiết bị, Tên thiết bị, Vị trí lắp đặt và ngày khởi tạo.

File sẽ được lưu vào thư mục Downloads của máy tính.
Chức năng xuất dữ liệu phục vụ báo cáo định kỳ và lưu trữ nội bộ cho Quản lý thiết bị.
Trạng thái: Sẵn sàng xuất file
